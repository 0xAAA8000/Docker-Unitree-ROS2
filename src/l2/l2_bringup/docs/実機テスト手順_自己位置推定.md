# L2 実機テスト手順(自己位置推定)

> `l2map` / `l2loc` はホスト PC 用のラッパースクリプト。launch で直接使う場合の対応:
> `l2map -s -r` = `ros2 launch l2_bringup mapping.launch.py save:=true record:=true`、
> `l2loc -a -r` = `ros2 launch l2_bringup localization.launch.py map:=地図.pcd auto_init:=true record:=true`。
> `l2eval` は `tools/l2eval`。

目的: L2 実機のデータを **一度記録** し、あとから `l2eval` で何度でも設定を比べられるようにする。
その場で調整はしない(記録さえあればオフラインで比べられる)。

## 準備
- L2 の電源は L1 のアダプタ(付属の 12V 1A は不安定)。PC は可能なら AC 電源。
- `nmcli con up unilidar-l2`、`ping 192.168.1.62` が通ること。
- 台車に L2 をしっかり固定する(テストの途中で付け直さない)。
- 空き容量: 記録は 1 時間で約 7 GB。

## 1. 地図を作る(記録つき)
```bash
l2map -s -r
```
1. 開始地点に台車を置き、床に**テープで印**をつける(向きもわかるように矢印で)。
2. 起動後 5 秒は動かさない(IMU 初期化)。
3. ゆっくり部屋を一周し、**印の位置・向きに戻って**から Ctrl+C。

→ 地図: `~/maps/l2_日時.pcd`、記録: `~/bags/l2map_日時`

## 2. 自己位置推定を試す(記録つき)
いずれも **印の位置・向きから開始**する(初期位置 = 地図の原点になる)。

| # | 内容 | 見ること |
| --- | --- | --- |
| A | 静止 1 分 | 推定位置のブレ |
| B | 部屋を一周して印に戻る(普通の速さ) | 戻ったときの位置のずれ、途中の位置飛び |
| C | B を速めに(早歩き) | 速く動いたときに見失わないか |
| D | 人や物が多い/動いている状態で一周 | 地図との違いに強いか |
| E | 印から 1 m・30° ずらして開始し、RViz の 2D Pose Estimate で合わせる | 初期位置のずれから復帰できるか |
| F | 部屋のいろいろな場所・向きに置いて `l2loc -a -r`(5 か所以上) | 開始位置の自動推定が当たるか、何秒かかるか |

```bash
l2loc -r            # 各テストごとに起動し直す(テストごとに別の記録になる)
```
テストの番号と記録フォルダ名(`~/bags/l2loc_日時`)の対応をメモしておく。

## 3. あとで比べる(L2 がなくてもできる)
```bash
# 今の設定で採点 (結果は ~/bags/l2loc_日時_eval/results.md に追記される)
l2eval ~/bags/l2loc_日時 ~/maps/l2_日時.pcd -n current

# 設定を変えて比べる例
l2eval BAG MAP -n leaf0.5  -- -p voxel_leaf_size:=0.5
l2eval BAG MAP -n map0.1   # MAP に間引いた地図を渡す
```
- 基準は同じ記録を Point-LIO で処理した軌跡(初回のみ作成、記録と同じ時間がかかる)。
- 見る値: 位置飛び (jumps)、Point-LIO とのずれ (RMSE / max)、採用しなかったスキャンの割合 (rejected)。
- テスト F はログの `start pose:` 行 (推定結果・一致率・2位の一致率・時間) と、置いた場所 (メジャーで測る) を記録しておく。
- テスト E は `-x -y -yaw` を付けずに (0, 0, 0) から始めれば、「初期位置が 1 m・30° ずれていたときに自力で戻れるか」を採点できる。
